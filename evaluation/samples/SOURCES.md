# Evaluation sources
These are test inputs, never runtime backing tracks. Originals downloaded unchanged; WAV derivatives are five-second decoded excerpts, without musical edits.

- AcousticGuitarSample.ogg — RyGuy, public domain. https://commons.wikimedia.org/wiki/File:AcousticGuitarSample.ogg . Excerpts 0–5 and 15–20 seconds.
- Blue.ogg — Skippy le Grand Gourou, public domain. https://commons.wikimedia.org/wiki/File:Blue.ogg . A blue-note scale example, not a full song or guaranteed real-guitar performance. Excerpt 0–5 seconds.
- Piano.ogg — copied from French Wikipedia, Commons upload by Loveless. CC BY-SA 3.0 / GFDL. https://commons.wikimedia.org/wiki/File:Piano.ogg ; https://creativecommons.org/licenses/by-sa/3.0/ . Excerpt 0–5 seconds; derivative under the same license.

Do not interpret these few examples as a representative music-quality benchmark.
