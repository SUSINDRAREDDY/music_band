# Asset credits

## Paper characters

The active character bodies are adapted from **Scribble Platformer by Kenney**, released under **CC0**.

- Source: https://kenney.nl/assets/scribble-platformer
- Original license: `public/assets/characters/paper-doodle/source-license.txt`
- Provenance: `public/assets/characters/paper-doodle/provenance.json`

Faces, limbs, accessories, instruments, and animated poses are adaptations authored for this application. The runtime uses the body paths in `bodies.json` and SVG rendering in `public/vendor/paper-doodle/`.

## Instrument samples

Instrument audio is fetched at runtime from the FluidR3_GM soundfont conversion hosted at https://paulrosen.github.io/midi-js-soundfonts/. Audio samples are not bundled in this repository.

## Libraries

ABC notation rendering and parsing use `abcjs`. Browser verification uses `playwright`. Their licenses are distributed with the installed packages.
